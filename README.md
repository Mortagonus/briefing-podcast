# briefing-podcast

Private podcast feed for Eric's daily Market Briefing audio (GitHub Pages).
Feed: https://mortagonus.github.io/briefing-podcast/feed.xml
Only the 10 most recent episodes are kept; the full archive is in Box › Stock Market › Audio Briefings.
Publish: `python3 tools/publish_podcast.py <repo> "Market Briefing YYYY.MM.DD (Audio).m4a"` then commit as a single orphan commit and force-push main.
